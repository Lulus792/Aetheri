# Protected unit inputs and exclusive connection custody

7 November 2026. Native C17 in the existing Fedora 44 Enforcing disposable
carrier, systemd 259.10-1.fc44. The full Aetheri goal remains incomplete.

## Implemented boundary

The new internal unit owner moves one exclusively supplied system-bus connection,
retains its original PID1 pin and copies a bounded independently admitted profile.
It duplicates protected source/drop-in FDs and joins held/named parent and file
objects, raw MAC, metadata and digests. Loaded aliases, fragments, drop-ins,
dependencies and selected service behavior must match. Only named perpetual
root/system slices can omit source files. The graph has one executable starter;
other nodes are non-executing infrastructure. Autonomous activation/restart paths,
privilege command flags and implicit journal streams are outside this P0 family.
This does not choose logging for the whole OS or change existing fixtures.

Subscribe and each RefUnit are attempted once with original authenticated
replies. Lost returns preserve original uncertainty. Start uses the existing
one-shot job observer, with source and connection checks after the final compiled
callout. A successful job keeps custody alive. Retirement requires independent
original-run/end/holder admission, then original loaded/ref identity and quiet
state before each one-shot UnrefUnit/Unsubscribe. Source fencing still permits
admitted cleanup. Explicit abandon closes without flushing the send queue; it
does not cancel delivered work, prove drain, settle SQL or release a lease.
Nested job callbacks preserve the outer method's busy bracket.

The caller still owes original unused allocation, volume/MAC/global mutation
admission and custody intent before acquisition. Native file observations are
not serialized allocation/volume authority. Drive this borrowed bus only; do not
mix other Ref/Subscribe/Start owners or the earlier job-only adapter on it.
The normal Root coordinator still needs protected profile registration, the full
custody lifetime and admitted end/recovery integration before normal app use.

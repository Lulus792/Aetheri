## Reviewed direction

Upstream identifies 5.4.9 as the final Lua 5.4 release, with later fixes generally
on 5.5. Merely replacing5.4.8 with5.4.9 would leave that maintenance problem.
The actual WirePlumber 0.5.19 meson.build already supports selecting Lua 5.5;
its installation guide's5.3/5.4 wording is older than that source check.
Select Lua 5.5.1 plus the four subsequent upstream fixes as a private candidate,
then rebuild the Lua-linked WirePlumber objects. No ABI alias from5.4 to 5.5.

The [new input recipe](../../../spec/audio-lua-inputs.json) pins the official
GitHub tag/archive, commit and six complete patched-file pre/postimages. The
combined patch contains only the C changes from the four separately fetched
upstream commits; original MIT notices remain in lua.h and the SDK COPYRIGHT.
The archive's complete known digest is checked before extraction. No source
makefile, package script, download or global install is run by the builder.

Sources reviewed 9 November 2026: [version history](https://www.lua.org/versions.html),
[known bugs and fixes](https://www.lua.org/bugs.html#5.5.1),
and [WirePlumber 0.5.19 source](https://github.com/PipeWire/wireplumber/blob/0.5.19/meson.build).
The four fixes cover GC signed-shift UB, NaN loop limits, negative-zero
subtraction and closing a coroutine during its error-close path. This is no
exhaustive security audit or permission to execute app-supplied Lua/bytecode.

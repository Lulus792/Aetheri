# Virtual HDA playback

## Boundary

Extend the original private audio transport into a separate diskless RAM guest.
The original carrier stays running on boot
`124d6ce8-6ff6-4ed8-a8c8-51aeaa87f056`; builds use new private mount/tmpfs
workspaces, ordinary UID1000 and enforcing carrier policy. No package, normal
source/build/service, frozen SQL/XML, authority, USB or user document changes.
The new RAM guest has no production SELinux policy. Its trusted fixed device
setup is not a normal authority, admission API, sandbox or HP audio proof.

The [contract](../../../spec/audio.md#diskless-hda-fixture) and
[input inventory](../../../spec/audio-hda-inputs.json) define the executed scope.
The new dependency is signed Fedora44 ALSA1.2.16.1-1.fc44; its selected library
and LGPL notice plus the existing PipeWire ALSA plugin total2,150,128 bytes.
Signature verification and extraction share sealed RPM snapshots. Eleven
same-kernel modules and ten existing runtime/notice objects are separately
hashed installed data, not newly signature-verified RPMs. No alsa-utils,
WirePlumber, Bluetooth or desktop service is added.

## Final executed boots

The final image retains the base preflight and adds only the dependent finite
audio test. Each boot gets a fresh UUID/NVRAM and original host child handle.
QMP stays on one protected AF_UNIX connection. The guest has no network, shared
folder, real disk or host sound backend. Capture begins before CPU execution.
Only after actual guest shutdown and `query-status=shutdown` does the controller
stop capture and explicitly quit the original QEMU. Its exit must be0.

The two cold boots independently pass complete ordered440/880Hz stereo at48kHz,
16-bit quantization, silent prefix/suffix, actual controller/mixer evidence and
UID1000 cap-zero/NNP server/player observations. Their WAV hashes are respectively
`dfc70244372ff2ce8d2d835957b6d3df22ebe697634a0421e12d6763d7faf91e` and
`0aeb6108a9e4e30158f2ea938f3f1f025e1f1a7ee54734b76223deb7b99a392b`.

The separate `boot-without-hda` keeps the same final image but omits the sound
card/backend. The guest fails at `reason=device`, starts neither audio actor,
powers off and exits through the observed host protocol. The countertest passes;
playback acceptance rejects this same evidence. A preflight or local drain alone
never proves audio. The WAV verifier also rejects the historical unfinalized,
silent and truncated artifacts without changing them.

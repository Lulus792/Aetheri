# Documentation

Current documentation is English, as requested on 25 October 2026.
Conversation and user explanations can remain German.

Inspected examples: [SerenityOS](https://github.com/SerenityOS/serenity/blob/master/README.md),
[Ladybird](https://github.com/LadybirdBrowser/ladybird/blob/master/README.md) and
[SecondBrain](https://github.com/Lulus792/SecondBrain/blob/main/README.md).

Use their useful principles, not copied passages: identify the project early,
state actual maturity, describe concrete tasks and link directly to useful material.

- Prefer plain sentences, concrete verbs and examples.
- README is an entry point, not an internal work log.
- Keep plans, implemented behavior and observed tests distinct.
- Document only existing commands and reproducible steps.
- Explain each module, service and dependency where a reader encounters it.
- Group related knowledge; add a page when it has a clear role.
- Keep generated output separate, bounded and understandable.
- Use real screenshots and downloads only.
- Retain archived source wording when needed for provenance; label its language
  and historical role. Do not maintain duplicate current German/English manuals.
